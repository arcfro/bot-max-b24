# bot-max-b24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поднять Nuxt-приложение рядом с dz-web: настройки MAX↔Битрикс24, auth из `ADMINS`, JSON-хранилище, полный inbox 1:1.

**Architecture:** Чистый Nuxt 4 scaffold без SQLite; копия `max-commands` / `max-bot` / `max-inbox` / `bitrix-crm` из `../dz-web`; persistence через `json-store` (`data/settings.json` + `data/state.json`); админ-сессия `nuxt-auth-utils` + plaintext `ADMINS` в env.

**Tech Stack:** Nuxt 4, Vue 3, TypeScript, Pinia, nuxt-auth-utils, Vitest. Без better-sqlite3 / Drizzle.

**Spec:** `docs/superpowers/specs/2026-09-22-bot-max-b24-design.md`

## Global Constraints

- Источник поведения: `/Users/arcfro/ingeo/dz-web` (sibling), не «улучшать» команды CRM.
- Env: `ADMINS` JSON-массив email/password; `NUXT_SESSION_PASSWORD`; `NUXT_PUBLIC_APP_URL`; опционально `DATA_DIR`.
- `/` = настройки, `/login` = вход; webhook `POST /api/max/webhook` без сессии.
- В `package.json` нет sqlite/drizzle.
- Коммиты частые по задачам; сообщения на русском или conventional — кратко.
